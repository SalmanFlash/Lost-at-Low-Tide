# Lost at Low Tide

You’re a cartographer stranded on a chain of islands. Raise and lower the tide to open paths, ride floating rafts, and recover three map fragments to find your way home. Changing the tide washes away your footprints.

## Run the game

Open **Godot 4.5.1 Standard**, import `game-off-2025-waves/project.godot`, and press **F5**. The project uses GDScript and the GL Compatibility renderer.

## Controls

| Action | Desktop |
|---|---|
| Move | WASD |
| Raise or lower the tide | ↑ / ↓ |
| Interact | E |
| Drop an item | Q |
| Open the menu | Tab |

Android uses on-screen controls. Walk over a map fragment to collect it. Restart the current level from the menu or choose **Play again** after finishing.
