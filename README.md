# Lost at Low Tide

Aap ek stranded cartographer hain. Tide badal kar teen map fragments jama karein aur ghar ka rasta dhoondein.

## Project

Godot **4.5.1 Standard**, GDScript aur GL Compatibility use karein. Godot Project Manager mein `game-off-2025-waves/project.godot` import karein aur **F5** se poora game chalayein.

Desktop par **WASD** move, **↑ / ↓** tide, **E** use, **Q** drop aur **Tab** menu ke liye hain. Android controls screen par hain. Fragment par chal kar usay collect karein. Menu se level restart hota hai. Completion screen se naya run shuru hota hai.
